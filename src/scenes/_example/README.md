# _example — pattern di riferimento, non attivo

`ExampleScrollScene.tsx` e `useLenis.ts` (in `src/hooks/`) mostrano il
pattern GSAP ScrollTrigger + Lenis descritto in `docs/MOTION-DESIGN.md`
(nell'hub `web-studio`). Nessuna pagina di questo template li importa.

Attivarli solo dopo che il brainstorming di un sito specifico ha confermato
di volere lo scroll-storytelling — poi copiare il pattern in
`src/scenes/<NomeScena>.tsx` reale, sostituendo il placeholder con il
contenuto vero del progetto.
